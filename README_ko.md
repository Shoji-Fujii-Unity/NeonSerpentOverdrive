## 🚀 실행 방법

1. `index.html` 을 브라우저에 끌어다 놓기（더블클릭 가능）
2. 난이도 칩 선택（이지 / 노멀 / 하드）
3. **게임 시작** → 카운트다운 후 플레이

## ⚔️ 사망 규칙（원작 승계）

| 상황 | 결과 |
|---|---|
| 자기 꼬리에 닿음 | 💀 게임 오버 |
| 머리가 AI 몸에 닿음 | 💀 게임 오버 |
| AI 머리와 정면 충돌 | 💀 게임 오버（AI도 함께 격파） |
| AI 머리가 내 몸에 부딪힘 | 🎉 **격파 +점수**, 흩어진 오브도 회수 |
| 벽 | ❌ 튕겨 나올 뿐 죽지 않음 |

- 시작 3초와 👻 파워업 중에는 **무적**（초록 링）. 무적 중에는 AI 쪽이 죽습니다
- **펄스로 스턴에 걸린 AI는 양쪽 접촉이 무효**（탈출의 열쇠）
- 이지에서만 **엑스트라 라이프** 1회（길이가 줄어 부활）

## ✨ 원작에서 개선한 점

1. **펄스가 공격과 방어를 겸합니다.** 오브를 끌어당기는 것(원작)에 더해, 범위의 AI를 약 1초 **스턴**시킵니다.
   스턴 중에는 정지하고 치명적이지 않습니다. 오버드라이브 중에는 더 길고 넓게 발동합니다.
2. **AI 두뇌를 새로 만들었습니다.** 자기 꼬리·다른 스네이크·벽을 전방 예측으로 회피하고, 플레이어 머리의 앞을 끊어
   **hunt**해 옵니다（점선으로 돌진 예고）. 평소에는 플레이어 몸을 피합니다.
3. **60초가 늘어납니다.** ⏳ **+5초**, 🧲 흡착, ✦ **점수 2배** 파워업 추가. ✂는 영구 효과가 아니며
   AI는 서서히 회복됩니다. 황금 오브(×5·움직임·소멸)와 3~5개 이어진 클러스터도 등장합니다.
4. **랭크와 오버드라이브.** `D → C → B → A → S → SS → S+` 실시간 판정, 랭크 업 연출,
   **콤보 ×12로 오버드라이브**（배경 물듦·음악 고조·펄스 강화）.
5. **프로시저럴 사운드트랙(Tone.js)**. 상황에 따라 레이어가 쌓입니다(메뉴＝패드+베이스 →
   플레이＝+킥 → 콤보 5·시간 15초 미만＝+드럼·알페지지 → 오버드라이브＝+리드). 효과음도 전부 합성음입니다.
6. **가독성·연출.** 블룸 발광, 심웨이브 태양과 원근 그리드, 리본 형태 스네이크 몸체,
   피격 비네트, 격파 히트스톱, 점수 플로팅, 연출 **FULL / SOFT / OFF**, 화질 **AUTO / HIGH / LOW**.
7. **기록과 다국어.** 난이도 태그 포함 상위 20건 저장, **원작 `neonSerpentScores` 자동 이월**（CLASSIC）,
   日本語 / English / 한국어 / 中文 즉시 전환.

## 🕹️ 공략

- hunt 해 오는 AI는 **끌어들이면 자기 몸에 부딪혀 자멸**합니다
- 펄스는 오브 무리에서만이 아니라 **포위됐을 때 탈출**에도
- ⏳ 으로 시간을 늘려 콤보 배율을 오래 유지하세요
- 👻 중에는 접촉이 한쪽만 죽입니다. 몸으로 AI를 쓸어낼 수 있습니다

## ⚙️ 기술 사양

| 항목 | 내용 |
|---|---|
| 구현 | HTML + CSS + 순수 JavaScript（파일 분할, **ES Module 미사용 → file:// 에서 동작**） |
| 그래픽 | Canvas 2D（다운샘플 블룸, 레이어 배경, 파티클） |
| 사운드 | **Tone.js 15.1.22**（BGM/효과음 procedural 합성） |
| UI 연출 | **GSAP 3.15.1**, **canvas-confetti 1.9.4** |
| 폰트 | Orbitron / Chakra Petch woff2 동봉（SIL OFL） |
| 저장 | localStorage（상위 20, 설정, 언어） |
| 네트워크 | 실행 중 통신 **0건**（모두 `vendor/` 에 동봉） |
