# 🐍 NEON SERPENT OVERDRIVE（ネオンスネーク・オーバードライブ）

**元作 [NEON SERPENT](../NeonSerpent/README_ja.md) の改良版**です。
60秒でハイスコアを狙うネオン・スネークアクションサバイバルの仕様はそのまま、
**AIの頭脳・パルスの使い道・見やすさ・音・演出**を全面的に強化しました。

  <img src="assets/screenshots/gameplay-overview.png" width="760" alt="NEON SERPENT OVERDRIVE ゲームプレイ" />
</p>

ブラウザだけで遊べます。**インストール不要・ローカルサーバー不要・オフライン動作**（ライブラリは同梱済み）。

---

## 🚀 遊び方

1. `index.html` をブラウザにドラッグ＆ドロップ（ダブルクリックでもOK）
2. 難易度チップ（イージー／ノーマル／ハード）を選ぶ
3. **ゲームスタート** → カウントダウン後にプレイ開始

> ファイルを開くだけで動きます。ネット接続は不要です（外部読み込みはゼロ）。

## 🎮 操作方法

| | PC | スマホ |
|---|---|---|
| 方向操作 | マウス移動（頭の向きたい方向を指す） | 画面をドラッグして方向指定 |
| 旋回（追加） | `← →` または `A D` キー | ― |
| パルス発射 | `スペース` | **ダブルタップ** or 右下 **PULSE** ボタン |
| ポーズ（追加） | `Esc` / `P` | 右上 ❚❚ ボタン |
| 再開 / 開始（追加） | `Enter` | ― |
| ミュージック切替（追加） | `M` | 🎵 ボタン |

> 💡 元作同様、**頭から40px以内のポインター位置は無視**されます。今回はプレイヤー周囲に点線で可視化しました。
> 💡 別のタブやウィンドウに切り替えると**自動でポーズ**します（戻ったら Esc / P で再開）。

## ⚔️ 死亡ルール（元作踏襲）

| 状況 | 結果 |
|---|---|
| 自分の尾に触れる | 💀 ゲームオーバー |
| AIスネークの体に頭が触れる | 💀 ゲームオーバー |
| AIの頭と正面衝突 | 💀 ゲームオーバー（ただしAIも道連れに撃破） |
| AIの頭を自分の体にぶつけさせる | 🎉 **撃破 +スコア**、零れたオーブも回収できる |
| 壁に触れる | ❌ 死なない（跳ね返るだけ） |

- 開始3秒と 👻 パワーアップ中は**無敵**（緑リング）。無敵中はAIのほうが死にます
- **パルスでスタンしたAIは接触が双方無効**（逃げ切り・逆転の切り札）
- イージーだけ**エクストラライフ**あり（死んでも1回だけ長さ減で復活）

## ✨ 元作からの改善ポイント

### 1. パルスが「攻めと防御」の両方になった
オーブを引き寄せる（元作踏襲）だけでなく、**範囲内のAIを約1秒スタン**させます。
スタン中のAIは停止し、接触死もしません。OVERDRIVE中はやや長く・大きく発動します。

### 2. AIの頭脳を刷新（サンプルスティアリング）
- 自分の尾・他スネーク・壁を**前方予測で回避**（自己破壊が減り、攻防が続く）
- 体が大きいと**プレイヤーの頭の先を切ってhunt**してくる（赤い点線で突進予告）
- プレイヤーの体は普段は回避、hunt中だけリスクを取る
- 難易度で追跡距離・攻撃性・パルス使用頻度が変化

### 3. 60秒が「伸ばす」ゲームになった
- ⏳ **+5秒**のタイムオーブ、🧲 吸引、✦ **スコア2倍** をパワーアップに追加
- ✂（AI短縮）は永続ではなくAIが少しずつ回復
- 稀に**ゴールデンオーブ（×5価値・動く・消える）**、3〜5個連なる**クラスター**が出現

### 4. ランクとOVERDRIVE
`D → C → B → A → S → SS → S+` をスコアでリアルタイム判定。HUDにランクバーを表示し、
ランクアップでトースト＋ファンファーレ。**コンボ×12でOVERDRIVE**（背景が染まり、音楽が加速し、パルスが強化）。

### 5. 手続き型サウンドトラック（Tone.js）
シンセウェイヴ風BGMをその場で合成。レイヤーが状況で増えます。
- メニュー／ポーズ：パッド＋ベース
- プレイ中：+ キック
- コンボ×5・残り15秒：+ スネア／ハイハット／アルペジオ
- OVERDRIVE：+ リードレイヤー

効果音もすべて合成音で、スコア取得はコンボ音程が上昇します。

### 6. 見やすさ・演出
- **ブルーム（グロー）**、シンセウェイヴの日没太陽と遠近グリッド、星、パーティクル強化
- 体の描画を**連続したリボン状**に変更（テカるコアライン付きで方向が読みやすい）
- 被弾時の赤ビネット、撃破時のヒットストップ＆シェイク、得点フロート表示
- 効果設定 **FULL / SOFT / OFF**、画質 **AUTO / HIGH / LOW**（AUTOは低FPSで自動降格）

### 7. 記録と多言語
- ハイスコアは**難易度タグ付きで上位20件**保存（スコア・最大コンボ・撃破数・日付）
- **元作 `neonSerpentScores` の記録を自動で引き継ぎ**（CLASSIC として表示）
- 日本語 / English / 한국어 / 中文（即時切替・UI全体）

## 🌟 パワーアップ（ダイヤ型）

| アイコン | 効果 |
|---|---|
| ⚡ | 速度アップ（+1.2、上限6） |
| 👻 | 5秒間無敵 |
| 📈 | 3体分伸長 |
| ✂ | AIを短縮（ゆっくり回復） |
| 🧲 | 8秒間、周囲のオーブを吸引 |
| ✦ | 8秒間、スコア2倍 |
| ⏳ | 残り時間 +5秒 |

> AIもパワーアップに寄っていきます。取り合いになるので早めに確保を。

## 🧩 難易度

| | AI体数 | スコア倍率 | 特徴 |
|---|---|---|---|
| イージー | 2 | ×1.0 | エクストラライフ1・AIは大人しい |
| ノーマル | 3 | ×1.25 | 元作に最も近い標準 |
| ハード | 4 | ×1.6 | hunt距離が長く、AIがパルスを使う |

## 🕹️ コツ

- hunt してきた AI は、少し待って**引き込めば自分の体に激突して自滅**します
- パルスはオーブ群の中心だけでなく、**囲まれた瞬間の脱出**に使う
- ⏳ を拾って時間を伸ばすとコンボ倍率のまま総取りできる
- 無敵（👻）中は接触が片側死になるので、体でAIを薙ぎ払える

## ⚙️ 技術仕様

| 項目 | 内容 |
|---|---|
| 実装 | HTML + CSS + 素のJavaScript（`js/` 分割・ES Module 不使用＝file:// で動く） |
| 描画 | Canvas 2D（ダウンサンプル合成によるブルーム、層背景、パーティクル） |
| 音声 | **Tone.js 15.1.22**（BGM/効果音の手続き合成） |
| UI演出 | **GSAP 3.15.1**（パネル／カウントダウン／スコアロール）、**canvas-confetti 1.9.4**（新記録演出） |
| フォント | Orbitron / Chakra Petch（woff2 同梱・SIL OFL） |
| 保存 | localStorage（ハイスコア上位20・設定・言語） |
| 対応 | 最新ブラウザ（PC / Android / iOS）、レスポンシブ、DPR自動調整 |
| 依存 | **すべて `vendor/` に同梱**。実行時のネットワーク通信はゼロ |

### ファイル構成

```
index.html          起動・HUD・各種パネル
css/style.css       ネオンUIスキン
js/i18n.js          4言語の文言
js/util.js          定数（元作踏襲値）・ランク・セーブ
js/audio.js         Tone.js リグ（BGM + SFX）
js/entities.js      スネーク / オーブ / パワーアップ / パルス / パーティクル
js/ai.js            AI（前方予測ステアリング・hunt・突進予告）
js/render.js        背景・ブルーム・スネーク描画
js/input.js         入力（マウス / タッチ / キー / PULSEボタン）
js/ui.js            HUD・パネル・トースト・記録表示
js/game.js          ルール・スコア・状態遷移・設定
vendor/             GSAP / canvas-confetti / Tone.js / woff2
tests/browser_test.ps1  ヘッドレスEdge（CDP）スモークテスト
```

### テスト

ヘッドレスEdgeで実機相当の確認ができます（ページエラー0・描画・音・多言語・記録）。

```powershell
powershell -ExecutionPolicy Bypass -File tests\browser_test.ps1            # PC (1280x720)
powershell -ExecutionPolicy Bypass -File tests\browser_test.ps1 -Mobile    # 携帯 (430x860)
```

`tests/shots/` にスクリーンショットが出力され、ページ例外・CDPエラー・FPS・ハイスコア保存まで検査します。
