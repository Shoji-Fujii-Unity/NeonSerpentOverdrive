# 🐍 NEON SERPENT OVERDRIVE（霓虹蛇 · 超载版）

原作 **[NEON SERPENT](../NeonSerpent/README_zh.md)** 的改良版。
60 秒霓虹蛇生存冲刺的核心规格全部继承，重点强化了 **AI 头脑、脉冲的攻防两用、可读性、音乐与演出**。

无需安装、无需本地服务器，**完全离线运行**（所有库已随包附带在 `vendor/`）。

---

## 🚀 开始游戏

1. 把 `index.html` 拖进浏览器（或双击打开）
2. 选择难度标签（简单 / 标准 / 硬核）
3. 点**开始游戏** → 倒数后开始

## 🎮 操作

| | 键盘鼠标 | 触屏 |
|---|---|---|
| 转向 | 移动鼠标（指向头要去的方向） | 在屏幕上拖动 |
| 转向（新增） | `← →` 或 `A D` | ― |
| 脉冲 | `空格` | **双击** 或 右下 **PULSE** 按钮 |
| 暂停（新增） | `Esc` / `P` | 右上 ❚❚ |
| 开始 / 重来（新增） | `Enter` | ― |

> 距头 40px 内的指针位置无效（原作规则），现在用虚线圈显示出来了。
> 切换到其他标签页或窗口会**自动暂停**。

## ⚔️ 死亡规则（继承原作）

| 情况 | 结果 |
|---|---|
| 碰到自己的尾巴 | 💀 游戏结束 |
| 头碰到 AI 身体 | 💀 游戏结束 |
| 与 AI 头正面相撞 | 💀 游戏结束（AI 同时被摧毁） |
| AI 头撞上你的身体 | 🎉 **击杀 +分数**，散落的光球也能吃 |
| 撞墙 | ❌ 只弹开，不会死 |

- 开局 3 秒与 👻 道具期间**无敌**（绿圈）。无敌时反而是 AI 会死
- **被脉冲眩晕的 AI 双方接触都无效**（被包围时的脱出手段）
- 只有简单难度有**额外生命**（复活时身体变短）

## ✨ 相对原作的改进

1. **脉冲攻防两用。** 除了吸来光球（原作），还会让范围内 AI **眩晕约 1 秒**：停下且不再致命。
   超载状态下脉冲更大、眩晕更久。
2. **AI 全新大脑。** 用前向预测躲避自己的尾巴、其他蛇和墙壁；体型占优时会**抢先卡位追击（hunt）**，
   并有红色虚线预警冲锋；平时则回避玩家身体。
3. **60 秒可以变长。** 新增 ⏳ **+5 秒**、🧲 吸引、✦ **分数双倍**；✂ 缩短不再是永久效果（AI 会缓慢恢复）；
   另有稀有的**金色光球（×5、会移动、会消失）**与 3~5 个连成一串的**光球簇**。
4. **段位与超载。** 实时判定 `D → C → B → A → S → SS → S+`，HUD 有段位进度条与晋级演出；
   **连击 ×12 进入 OVERDRIVE**（背景染色、音乐升级、脉冲增强）。
5. **程序化音乐（Tone.js）。** 层随情况叠加：菜单＝pad+低音 → 游戏中＋底鼓 →
   连击 ≥5 或剩余 15 秒＋鼓组/琶音 → 超载＋主音。音效也全部实时合成，吃球音高随连击上升。
6. **画面与手感。** 泛光（bloom）、合成波落日与透视网格、蛇身改为连续缎带并带高亮核心、
   受伤红色暗角、击杀顿帧与震屏、分数飘字；效果 **FULL / SOFT / OFF**，画质 **AUTO / HIGH / LOW**（低帧自动降级）。
7. **记录与多语言。** 前 20 条成绩带难度标签（分数 / 最大连击 / 击杀 / 日期），
   **自动继承原作 `neonSerpentScores`**（显示为 CLASSIC）；界面即时切换 日本語 / English / 한국어 / 中文。

## 🌟 强化道具（菱形）

| 图标 | 效果 |
|---|---|
| ⚡ | 速度 +1.2（上限 6） |
| 👻 | 无敌 5 秒 |
| 📈 | 伸长 3 节 |
| ✂ | 缩短 AI（会缓慢恢复） |
| 🧲 | 8 秒吸引周围光球 |
| ✦ | 8 秒分数双倍 |
| ⏳ | 剩余时间 +5 秒 |

> AI 也会来抢道具，尽早拿到。

## 🧩 难度

| | AI 数量 | 分数倍率 | 特点 |
|---|---|---|---|
| 简单 | 2 | ×1.0 | 额外生命 1，AI 温和 |
| 标准 | 3 | ×1.25 | 最接近原作 |
| 硬核 | 4 | ×1.6 | 追击距离更长，AI 会使用脉冲 |

## 🕹️ 技巧

- 追击你的 AI 只要**让它继续冲，就会撞到你的身体而自灭**
- 脉冲不只是在光球堆里放，**被围住时用它脱身**
- 捡 ⏳ 延长时间，让高倍连击继续赚钱
- 👻 期间接触是单向死亡，可以用身体横扫 AI
